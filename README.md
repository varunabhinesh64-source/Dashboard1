# TaskFlow – Personal Task Dashboard

A clean, modern single-page To-Do / Task Dashboard built with pure HTML, CSS, and vanilla JavaScript.

**Perfect mini-project for learning + portfolio.**

## Features

- ✅ Add, edit, delete, and complete tasks
- 🎯 Priority levels (High / Medium / Low) with color coding
- 🏷️ Categories / tags
- 📅 Due dates (overdue tasks highlighted in red)
- 🔍 Live search
- 📊 Filters (All / Active / Completed + Priority filter)
- 📈 Live stats + progress bar
- 🌙 Dark / Light mode (persisted)
- 💾 LocalStorage persistence (no backend needed)
- 📱 Fully responsive
- ✨ Smooth animations

## Tech Stack

- HTML5
- CSS3 (Custom Properties / CSS Variables for theming)
- Vanilla JavaScript (ES6+)
- LocalStorage API

No frameworks, no build tools, no dependencies.

## How to Run

1. Clone this repository
2. Open `index.html` in any modern browser

That's it! No server required.
